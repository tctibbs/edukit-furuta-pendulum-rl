# Milestone 02: The Furuta model in Isaac Lab

Get the pendulum environment working in Isaac Lab, defined from the values provided in the manual.

## Goals

- [ ] The derived inertia survives into the simulation.
- [ ] The rotor holds a commanded position, replicating the hardware's stepper.
- [ ] The environment registers and runs at 1, 512, and 4096 parallel environments.
- [ ] The articulation is able to be regenerated directly from the parameter file.
