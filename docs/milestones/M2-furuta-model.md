# Milestone 02: the Furuta model in Isaac Lab

Get the pendulum environment working in Isaac Lab, defined from the values provided in the manual.

## Goals

- [x] The derived inertia survives into the simulation.
- [x] The rotor holds a commanded position, replicating the hardware's stepper.
- [x] The environment registers and runs at 1, 512, and 4096 parallel environments.
- [x] The articulation regenerates directly from the parameter file.
