# Milestone 03: Hardware bring-up and system identification

Measure the physical system and refit the simulation from those measurements.

## Goals

- [ ] The supplied firmware is verified through swing up and balance.
- [ ] Serial round-trip time is measured to determine the deployment target.
- [ ] Every physical constant the simulation defines is measured from the physical unit.
- [ ] Traces are captured on the physical system to serve as a golden reference for the simulation.
