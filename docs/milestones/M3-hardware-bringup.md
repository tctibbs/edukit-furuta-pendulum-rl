# Milestone 03: Hardware bring-up and system identification

Measure the physical system and refit the simulation from those measurements.

## Goals

- [x] The supplied firmware is verified through swing up and balance.
- [x] Serial round-trip time is measured to determine the deployment target.
- [x] Every physical constant the simulation defines is measured from the physical unit.
- [x] Traces are captured on the physical system to serve as a golden reference for the simulation.
