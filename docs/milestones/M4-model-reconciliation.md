# Milestone 04: reconcile the simulation to the measured system

Reproduce in simulation the behavior of the measured system from [Milestone 03](M3-hardware-bringup.md).

## Goals

- [ ] A reconciliation harness drives the simulated model through the same probes the hardware ran, and compares the two with the same analysis code.
- [ ] Each discrepancy Milestone 03 measures is either represented in the model or recorded as a known gap.
- [ ] The reconciled simulation reproduces a logged hardware trace.
