# Runbooks

A runbook is a procedure for setting up or operating part of this project.

- [Training host setup](training-host-setup.md), how to build the Isaac Lab environment
- [Edukit assembly](edukit-assembly.md), building the unit and the measurements to take before parts become unreachable
- [Running the Edukit firmware](edukit-firmware.md), flashing, the boot modes, the serial link, and rebuilding the image
